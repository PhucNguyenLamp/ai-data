- Objectives:

  • Learn how to use Nsight Compute to profile kernels.

  • Apply kernel optimization techniques such as vectorization and shared memory swizzling.

- Topics:

  • Introduction to Nsight Compute and GPU optimization techniques

  • The roofline model and compute-bound vs. memory-bound analysis

  • Kernel optimization techniques:

    •   Memory coalescing and vectorized memory access

    •   Shared memory tiling and bank-conflict avoidance (swizzling)

    •   Register and occupancy tuning

    •   Loop unrolling and instruction-level parallelism (ILP)

    •   Warp-level primitives (shuffle and warp-level reductions)

    •   Asynchronous copies (cp.async) and software prefetching

    •   Launch configuration tuning (block and grid sizing)
