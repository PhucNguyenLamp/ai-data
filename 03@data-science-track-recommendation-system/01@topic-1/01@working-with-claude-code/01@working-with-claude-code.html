Mục tiêu: Làm quen với Claude Code — công cụ agentic coding của Anthropic — và các khóa học liên quan để tăng hiệu suất coding, tự động hóa tác vụ và áp dụng vào workflow của team.

Nội dung chính:

  1. Tổng quan Claude Code: agentic coding tool chạy trong terminal/IDE, đọc hiểu codebase, chỉnh sửa nhiều file, chạy lệnh và tích hợp git (tạo branch, commit, mở PR).

  2. Cài đặt & khởi động: cài qua npm (@anthropic-ai/claude-code) hoặc Homebrew/WinGet, dùng extension cho VS Code/JetBrains, chạy claude trong thư mục dự án và đăng nhập.

  3. Cấu hình & quản lý context: dùng CLAUDE.md để lưu convention/quy ước dự án, /init để sinh file khởi tạo, và /clear, /compact để quản lý context window trong session dài.

  4. Mở rộng năng lực: Agent Skills (SKILL.md), subagents để tách context và delegate tác vụ, hooks, và tích hợp MCP servers để kết nối tool/dịch vụ ngoài.

  5. Áp dụng theo convention team: chuẩn hóa CLAUDE.md, chia sẻ skills nội bộ, dùng cho code review, viết test, sinh tài liệu và tự động hóa workflow lặp lại.
