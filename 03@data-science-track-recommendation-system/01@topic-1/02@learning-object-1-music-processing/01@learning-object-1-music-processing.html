Mục tiêu: Nắm vững xử lý tín hiệu âm nhạc/audio (music processing) làm nền tảng đầu vào cho các bài toán ML/DL phân loại và recommendation content (song).

Nội dung chính:

  1. Cơ bản về tín hiệu audio: waveform, sample rate, bit depth, mono/stereo, đọc/ghi file (wav/mp3/flac) và resampling về cùng sample rate.

  2. Biểu diễn miền tần số: STFT, spectrogram, mel-spectrogram, MFCC, chroma — chọn representation phù hợp cho model (CNN trên spectrogram, embedding từ pretrained audio model như MERT).

  3. Feature extraction: đặc trưng truyền thống (tempo/BPM, beat, zero-crossing rate, spectral centroid/rolloff, energy) và embedding học sâu; chuẩn hóa & xử lý độ dài biến thiên (padding/cropping, fixed-length segment).

  4. Data augmentation cho audio: time-stretch, pitch-shift, add noise, time/frequency masking (SpecAugment) để tăng robustness và giảm imbalance.

  5. Pipeline tiền xử lý quy mô lớn: batching, chuẩn hóa I/O, cache đặc trưng, và tích hợp với luồng training/serving (nối tiếp phần Spark data processing & modeling).
