Mục tiêu: Thành thạo các công cụ Data Science/MLOps được dùng xuyên suốt pipeline của hệ thống Music Recommendation.

Nội dung chính:

  1. Spark: xử lý dữ liệu quy mô lớn, feature engineering phân tán.

  2. Kafka: streaming sự kiện tương tác (play/skip/like) phục vụ predict on-the-fly.

  3. MLflow: quản lý thí nghiệm, tracking metric, model registry.

  4. Airflow: orchestrate các data/ML pipeline theo lịch và phụ thuộc.

  5. S3: lưu trữ dataset, artifact, model.

  6. Kubernetes (K8s): triển khai và scale service serving model.
