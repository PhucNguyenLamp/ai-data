Mục tiêu: Triển khai model serving predict on-the-fly và vận dụng AI Agents (LLM) theo convention của team.

Nội dung chính:

  1. Model serving: đóng gói model, xây dựng API (REST/gRPC) predict real-time, tích hợp với luồng Kafka.

  2. Triển khai và scale service trên Kubernetes; theo dõi latency và độ ổn định.

  3. AI Agents (LLM): dùng LLM hỗ trợ sinh tag/mô tả content, hỗ trợ coding và tài liệu theo quy ước team.

  4. Document đầy đủ/chi tiết từng phần trong flow (modeling, serving) — tiêu chí Basic; nâng cao: customize model, trích xuất embedding, đóng góp agent skills cho team.
