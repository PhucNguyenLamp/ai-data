Mục tiêu: Hiểu giai đoạn đầu tiên của ML project — khai phá (EDA) và xử lý dữ liệu cho bài toán phân loại content (song) của hệ thống Music Recommendation.

Nội dung chính:

  1. Thu thập và hiểu dữ liệu song: metadata (genre, artist, duration), audio features, và tương tác người dùng (play, skip, like).

  2. Exploratory Data Analysis (EDA): phân phối nhãn, dữ liệu thiếu, imbalance giữa các lớp content.

  3. Xử lý dữ liệu quy mô lớn với Spark: làm sạch, chuẩn hóa audio features, feature engineering, tạo dataset sẵn sàng cho training.

  4. Xây dựng data pipeline có thể tái lập phục vụ các bước modeling & serving sau này.
